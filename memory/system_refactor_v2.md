**重构目标**：用真实最新 A 股数据模拟实盘，验证策略有效性，为进入实盘做准备

**重构完成日期**：2026-03-30

**完成内容**：

1. Phase 1 - 数据-交易核心链路
   - 实时价格缓存 (realtime_feed.py): Sina 主源 + Tushare 备用，10秒刷新
   - 主交易循环重构：接入实时价格 + 防重复下单

   - 日线自动更新器：盘后 16:10 自动更新

2. Phase 2 - 策略信号时机修正

3. Phase 3 - 性能追踪与 Web 看板
   - 性能指标计算 (metrics.py): 夏普/回撤/信息比/胜率
   - Web 监控 v2.0: WebSocket 实时推送 + REST API
   - 钉钉通知增强：每日日报 + 回撤 >5% 告警

4. Phase 4 - 扩大验证范围
   - 5 年历史数据脚本 (fetch_5year_data.py)
