# 中国股票量化自动交易系统 - 项目记忆

## 项目信息
- 仓库：https://github.com/difeizheng/auto-transaction
- 版本：1.0
- 启动时间：2026-03-19

## 快速启动命令

### 1. Web 监控界面
```bash
python web_server.py
# 访问 http://localhost:8801
```

### 2. 模拟交易
```bash
python main.py paper --strategy optimal --paper-capital 100000
```

### 3. 回测
```bash
# 使用原始股票池
python main.py backtest --strategy optimal --capital 1000000

# 使用扩展股票池 + 基本面过滤
python main.py backtest --strategy optimal --use-extended-pool --start-date 20250101 --end-date 20260319
```

### 4. 定时任务调度器
```bash
python start_services.py scheduler
```

## 系统架构

| 模块 | 文件 | 功能 |
|------|------|------|
| 数据采集 | `src/data_collector/` | Tushare/Baostock 接口 |
| 策略 | `src/strategy/` | 最优策略/增强 MA/技术指标 |
| 回测 | `src/backtest/` | 回测引擎 + 绩效分析 |
| 交易 | `src/trader/` | PaperBroker/风控/调度 |
| Web | `web_server.py` | FastAPI 监控面板 |

## 核心策略参数

### 最优参数组合 (2026-03-20 参数敏感性测试)

**激进型 (最高收益)**:
- 止损：**5%**
- 止盈：**25%**
- 信号阈值：**4.0/7 分**
- 趋势过滤：必须 trend_ok=True
- 回测表现：年化 7.02%, 夏普 0.38, 回撤 9.90%, 胜率 42.9%

**稳健型 (最高夏普)**:
- 止损：**10%**
- 止盈：**25%**
- 信号阈值：**4.0/7 分**
- 趋势过滤：必须 trend_ok=True
- 回测表现：年化 6.23%, 夏普 0.39, 回撤 9.09%, 胜率 50.0%

### 信号评分权重
- 均线金叉 1.5 分、MACD 1.0 分、RSI 健康 0.5 分、RSI 超卖 0.5 分
- 布林带下轨 1.0 分、成交量 1.0 分、趋势向上 1.0 分

### 移动止损：盈利 12% 后触发

### 市场状态：双均线 +3 日确认 + 成交量过滤
