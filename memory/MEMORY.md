## 项目信息
- 仓库：https://github.com/difeizheng/auto-transaction
- 版本：1.0
- 启动时间：2026-03-19

## 快速启动命令

### 1. Web 监控界面
```bash
python web_server.py
# 访问 http://localhost:8801
```

### 2. 模拟交易
```bash
python main.py paper --strategy optimal --paper-capital 100000
```

### 3. 回测
```bash
# 使用原始股票池
python main.py backtest --strategy optimal --capital 1000000

# 使用扩展股票池 + 基本面过滤
python main.py backtest --strategy optimal --use-extended-pool --start-date 20250101 --end-date 20260319
```

### 4. 定时任务调度器
```bash
python start_services.py scheduler
```

## 核心策略参数

### 最优参数组合 (2026-03-24 参数网格搜索 - 27 组测试)
测试范围：止损 4%-6%, 止盈 25%-35%, 信号阈值 4.0-5.0

**最优参数**:
- 止损：**4%**
- 止盈：**30%**
- 信号阈值：**5.0** (综合评分最高)

**回测表现 (20240324-20260323, 5 只股票)**:
| 指标 | 数值 | 目标 |
|------|------|------|
| 年化收益 | 7.90% | ≥15% |
| 夏普比率 | 0.44 | ≥1.0 |
| 最大回撤 | 12.72% | ≤15% ✅ |
| 胜率 | 48.2% | ≥55% |
| 盈亏比 | 2.17 | ≥2.0 ✅ |

**参数敏感性分析**:
- 止损 4% 优于 5%/6% (更紧止损更优)
- 止盈 30% 优于 25%/35% (中等止盈最优)
- 阈值 4.5-5.0 表现接近 (高阈值略优)
- 评分公式：Sharpe*0.4 + Annual*0.3 + (WinRate-0.4)*0.2 + (ProfitFactor-1.5)*0.1

### 2026-03-24 扩展参数搜索 (48 组测试)
测试范围：止损 3%-5%, 止盈 30%-45%, 信号阈值 4.5-6.0

**结论**: 参数优化已达瓶颈，最优参数仍为 SL=4%, TP=30%, Thr=4.5-5.0
- 年化收益上限：~7.9%
- 无法通过参数调整突破 15% 目标

**关键发现**:
- 止盈 40%-45% 时胜率提升至 49%, 但交易次数减少 (107 vs 113)
- 阈值>5.5 时信号过度过滤，年化降至 3-5%
- 止损 3% 与 4% 表现相近，但 3% 更容易被震荡出局

**后续方向**: 需要策略层面改进而非参数优化
1. 改进入场信号质量 (提高胜率)
2. 优化出场策略 (提高盈亏比)
3. 增加市场状态自适应
4. 股票池优化 (高质量股票筛选)
