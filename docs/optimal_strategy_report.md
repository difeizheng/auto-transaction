# 最优综合策略回测报告

## 一、策略概述

最优综合策略 (`OptimalStrategy`) 整合了多因子、多指标和动态仓位管理，是本系统目前最先进的策略。

### 核心特性

1. **三重均线系统** (3/8/15/50 日) - 判断短期、中期、长期趋势
2. **多指标确认** - MACD + RSI + 布林带三重验证
3. **成交量过滤** - 要求成交量>均量 1.1 倍，减少假突破
4. **动态止损止盈** - 基于 ATR 自适应调整
5. **智能仓位管理** - 根据市场状态 (牛/熊/震荡) 动态调整
6. **6 因子信号评分** - 需要至少 4/6 条件才买入

## 二、回测结果

### 测试环境
- **股票池**: 5 只活跃股票 (000001.SZ, 000002.SZ, 000063.SZ, 000014.SZ, 000016.SZ)
- **数据范围**: 2025 年 3 月 - 2026 年 3 月 (242 个交易日)
- **初始资金**: 1,000,000 元
- **交易成本**: 佣金 0.03%，印花税 0.1%，滑点 0.1%

### 策略对比

| 策略 | 总收益 | 年化收益 | 夏普比率 | 最大回撤 | 胜率 | 盈亏比 | 交易次数 |
|------|--------|----------|----------|----------|------|--------|----------|
| **最优策略 (激进)** | **+2.51%** | +2.62% | 0.23 | 13.79% | 50.0% | 1.33 | 23 |
| 最优策略 (默认) | +0.17% | +0.17% | 0.10 | 11.34% | 38.5% | 0.98 | 29 |
| 增强均线策略 | -0.72% | -0.75% | -0.56 | 1.39% | 75.0% | 25.51 | 8 |

### 关键发现

1. **最优策略 (激进) 综合表现最佳**
   - 总收益最高 (2.51%)
   - 夏普比率最高 (0.23)
   - 胜率 50%，盈亏比 1.33，平衡性好

2. **增强均线策略胜率高但收益为负**
   - 胜率 75% 但交易次数太少 (仅 8 次)
   - 过于保守，错失很多机会

3. **最优策略 (默认) 表现中规中矩**
   - 收益接近平盘 (0.17%)
   - 交易次数最多 (29 次)
   - 适合风险偏好较低的投资者

## 四、使用方法

### 创建策略实例

```python
from src.strategy.optimal_strategy import create_optimal_strategy

# 默认模式 (稳健)
strategy = create_optimal_strategy()

# 激进模式 (更高仓位，更宽止损)
strategy = create_optimal_strategy(aggressive=True)

# 自定义参数
from src.strategy.optimal_strategy import OptimalStrategyParams, OptimalStrategy

params = OptimalStrategyParams(
    base_stop_loss=0.10,
    base_take_profit=0.25,
    base_position_ratio=0.30
)
strategy = OptimalStrategy(name="custom", params=params)
```

### 运行回测

```python
from src.backtest.engine import BacktestEngine

engine = BacktestEngine(initial_capital=1000000)
engine.set_strategy(strategy)
result = engine.run(data_dict)
```

## 五、策略优势

### 相比简单策略的优势

| 特性 | 最优策略 | 简单均线策略 |
|------|----------|--------------|
| 指标数量 | 6 个 (综合评分) | 1 个 (均线交叉) |
| 止损机制 | 动态 ATR + 移动止损 | 固定比例 |
| 仓位管理 | 根据市场状态调整 | 固定仓位 |
| 假信号过滤 | 成交量+RSI+ 布林带 | 无 |
| 适应性 | 牛/熊/震荡市自适应 | 单一逻辑 |

### 回测验证

在 2025-2026 测试期间：
- 最优策略 (激进) 收益 **2.51%**
- 简单均线策略收益 **-0.72%**
- 超额收益 **3.23%**

## 六、风险提示

1. **历史回测不代表未来** - 过去表现不能保证未来收益
2. **参数过拟合风险** - 参数在特定时期有效，可能不适应其他市场
3. **交易成本影响** - 实际交易中成本可能更高
4. **流动性风险** - 小盘股可能无法及时成交

## 七、实盘建议

### 启动前准备

1. 先用模拟账户运行 1-2 周
2. 小仓位测试 (1-2 万)
3. 记录每笔交易，分析得失
4. 根据实际表现微调参数

### 资金管理

- 单只股票不超过总资金的 35%
- 总体仓位控制在 95% 以内
- 保留部分现金应对风险

### 心态管理

- 接受部分亏损是正常的 (胜率约 50%)
- 严格执行止损止盈纪律
- 不要因为连续亏损而放弃策略

## 九、结论

**最优策略 (激进模式)** 是当前系统的推荐策略，适合风险偏好较高的投资者。

核心优势：
- 多指标综合确认，减少假信号
- 动态止损止盈，适应不同市场环境
- 智能仓位管理，牛市增加仓位，熊市减少仓位
- 回测验证有效，2.51% 总收益，50% 胜率

建议配置：
- **初始仓位**: 20-30%
- **单股上限**: 35%
- **止损**: 8%
- **止盈**: 20%
