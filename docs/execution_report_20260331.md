## ⚠️ 发现的问题

### 问题1: Tushare API 限流

**现象**:
```
ERROR - 获取日线数据失败：抱歉，您每分钟最多访问该接口50次
```

**影响**:
- 系统初始化时频繁调用 Tushare
- 导致部分股票数据获取失败
- 可能影响策略执行

**解决方案**:
1. 优化数据获取逻辑，减少 API 调用
2. 使用数据库缓存，避免重复获取
3. 增加请求间隔（当前 0.3 秒 → 建议 1 秒）
4. 优先使用 Sina 实时数据，Tushare 仅作备用

**影响**: 轻微（系统会自动切换到 Tushare 备用数据）
