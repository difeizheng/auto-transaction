## 手动控制命令

### 查看运行状态
```bash
# 查看进程
tasklist | findstr python

# 查看日志
tail -f logs/trader.log
```

### 停止服务
```bash
# 找到进程 PID 后
taskkill /F /PID <进程 ID>
```

### 重启服务
```bash
python run_paper_trading.py
```
