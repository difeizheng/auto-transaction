### 5.2 数据补全方案

#### 目标数据量

| 数据类型 | 时间范围 | 股票数 | 预计记录数 |
|---------|---------|--------|-----------|
| 日线行情 | 2023-01-01 ~ 2026-03-31 | 46 | ~35,000 |
| 分钟线 | 最近 3 个月 | 46 | ~200,000 |
| 财务指标 | 最近 12 季度 | 46 | ~550 |
| 交易日历 | 2023-2026 | - | ~750 |

#### 数据获取脚本

```python
# scripts/补全历史数据.py
"""
补全 3 年历史数据
"""
import tushare as ts
from tqdm import tqdm
from src.utils.database import db

def fetch_3year_data():
    """获取 3 年历史数据"""
    stock_pool = settings.DEFAULT_STOCK_POOL
    start_date = '20230101'
    end_date = datetime.now().strftime('%Y%m%d')

    for ts_code in tqdm(stock_pool, desc="获取日线数据"):
        try:
            # 获取日线
            df = ts.pro_bar(
                ts_code=ts_code,
                start_date=start_date,
                end_date=end_date,
                adj='qfq'  # 前复权
            )

            # 写入数据库
            db.insert_df(df, 'daily_quotes', if_exists='append')

            time.sleep(0.2)  # 限速
        except Exception as e:
            print(f"获取 {ts_code} 失败: {e}")

    print(f"数据补全完成，共 {len(stock_pool)} 只股票")

if __name__ == "__main__":
    fetch_3year_data()
```

### 5.4 问题修复预案

#### 预期问题1：数据类型错误

**症状**：
```
TypeError: cannot convert the series to <class 'float'>
```

**原因**：pandas DataFrame 列访问返回 Series

**修复**：
```python
# 错误写法
price = bar.get('close', 0)  # bar 是 DataFrame

# 正确写法
price = float(bar['close'].iloc[0]) if not bar.empty else 0
```

---

#### 预期问题2：表不存在

**症状**：
```
sqlite3.OperationalError: no such table: signals
```

**修复**：
```bash
# 运行数据库初始化脚本
python scripts/init_all_tables.py
```

---

#### 预期问题3：实时数据获取失败

**症状**：
```
[RealtimeFeed] Sina 数据获取失败，切换到 Tushare
[RealtimeFeed] Tushare 数据获取失败
```

**修复**：
1. 检查网络连接
2. 检查 Tushare Token 是否有效
3. 降低刷新频率（10秒 → 30秒）
4. 使用缓存数据兜底

---

#### 预期问题4：信号重复生成

**症状**：
```
[SignalScheduler] 今日已生成信号，跳过
[SignalScheduler] 今日已生成信号，跳过
...
```

**原因**：日期判断逻辑错误

**修复**：
```python
# 在 signal_scheduler.py 中
def generate_signals(self):
    current_date = datetime.now().strftime('%Y%m%d')

    # 检查今日是否已生成
    if self._last_signal_date == current_date:
        trader_logger.info("今日已生成信号，跳过")
        return []

    # 生成信号...
    self._last_signal_date = current_date
```
