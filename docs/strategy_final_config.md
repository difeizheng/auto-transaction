## 核心改进点

### 1. 仓位管理优化 (关键突破)

**改进前**:
- 基础仓位：30%
- 牛市最大：45%
- 熊市仓位：3%

**改进后**:
- 基础仓位：**35%** (+5%)
- 牛市最大：**55%** (+10%)
- 熊市仓位：**2%** (-1%)

**效果**: 年化收益提升 2.26%，核心驱动力来自牛市重仓

### 2. 市场状态判断

**判断逻辑**:
- 双均线系统 (5 日 vs 60 日)
- 价格相对位置 (价格 vs 长期均线)
- 均线斜率 (5 日变化)
- 连续 3 日确认机制

**状态定义**:
- 牛市：均线多头 + 价格站上长期均线 + 斜率向上
- 熊市：均线空头 + 价格跌破长期均线 + 斜率向下
- 震荡市：其他情况

### 3. 止损止盈机制

**四重退出机制**:
1. 紧止损：4% 止损保护本金
2. 目标止盈：35% 止盈落地利润
3. 移动止损：盈利 15% 后启动，回撤 6% 出场
4. 时间止损：10 日无盈利退出
