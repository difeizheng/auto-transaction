## 系统架构

### 模块组成

```
auto-transaction/
├── src/
│   ├── data_collector/
│   │   ├── sina_client.py      # 新浪财经实时行情 (新增)
│   │   ├── tushare_client.py   # Tushare 日线数据
│   │   └── data_manager.py     # 数据管理器
│   │
│   ├── trader/
│   │   ├── easytrader_broker.py    # easytrader 券商接口 (新增)
│   │   ├── broker_api.py           # 券商接口封装 (已增强)
│   │   ├── realtime_monitor.py     # 实时监控模块 (新增)
│   │   ├── emergency_handler.py    # 紧急处理模块 (新增)
│   │   └── risk_control.py         # 风险控制 (已增强)
│   │
│   └── strategy/
│       └── optimal_strategy.py     # 交易策略
│
├── config/
│   ├── settings.py                 # 系统配置 (已增强)
│   └── broker_config.json          # 券商配置 (需创建)
│
└── web_server.py                   # Web 监控服务器
```

### 数据流

```
实时行情 (Sina) → 策略计算 → 风控检查 → 券商接口 (easytrader) → 交易所
                                                              ↓
钉钉通知 ← 成交结果 ← 订单状态 ←                      委托队列
```

## 安装步骤

### 1. 安装 Python 依赖

```bash
# 核心依赖
pip install easytrader requests pandas numpy

# 可选依赖（数据源）
pip install tushare akshare

# 完整依赖
pip install -r requirements.txt
```

### 2. 配置券商账户

**步骤 1**: 复制配置示例
```bash
cp config/broker_config.json.example config/broker_config.json
```

**步骤 2**: 编辑 `config/broker_config.json`
```json
{
  "user": "你的证券账号",
  "password": "你的登录密码",
  "comm_password": "你的交易密码"
}
```

### 3. 配置环境变量

**步骤 1**: 复制环境变量示例
```bash
cp .env.example .env
```

**步骤 2**: 编辑 `.env` 文件
```bash
# 实盘模式配置
REAL_TRADING_MODE=true
REAL_BROKER_TYPE=huatai
REAL_BROKER_CONFIG_PATH=config/broker_config.json

# 钉钉通知（可选）
ENABLE_DINGDING_NOTIFY=true
DINGDING_WEBHOOK=https://...
```

### 4. 初始化数据库

```bash
python src/utils/database.py
```

## 配置说明

### 实盘模式开关

| 配置项 | 位置 | 说明 |
|--------|------|------|
| `REAL_TRADING_MODE` | `.env` | `true`=实盘，`false`=模拟 |
| `PAPER_TRADING` | `.env` | `true`=模拟盘，`false`=实盘 |

### 券商配置

支持以下券商：

| 券商 | 配置值 | 客户端 |
|------|--------|--------|
| 华泰证券 | `huatai` | htzq |
| 银河证券 | `yinhai` | yh_client |
| 国金证券 | `guojin` | gj_client |
| 中金财富 | `cicc` | cicc |

### 风控参数

实盘模式下的风控参数（可在 `settings.py` 中调整）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_position_ratio` | 80% | 最大仓位比例 |
| `max_stock_position_ratio` | 25% | 单只股票最大持仓 |
| `stop_loss_ratio` | 8% | 止损比例 |
| `take_profit_ratio` | 20% | 止盈比例 |
| `large_order_threshold` | 50000 | 大额订单阈值（元） |

## 使用示例

### 示例 1：手动测试券商连接

```python
from src.trader.broker_api import RealBroker

# 创建实盘券商实例
broker = RealBroker(
    broker_type='huatai',
    config_path='config/broker_config.json'
)

# 连接
if broker.connect():
    print("连接成功!")

    # 获取账户信息
    account = broker.get_account_info()
    print(f"总资产：{account['total_asset']}")
    print(f"可用资金：{account['available_cash']}")

    # 获取持仓
    positions = broker.get_positions()
    for pos in positions:
        print(f"{pos['ts_code']}: {pos['volume']}股")

    # 断开连接
    broker.disconnect()
else:
    print("连接失败")
```

### 示例 2：获取实时行情

```python
from src.data_collector.sina_client import SinaClient

client = SinaClient()

# 获取单只股票
data = client.get_single_stock('000001.SZ')
if data:
    print(f"平安银行 现价：{data['price']} 涨跌幅：{data['pct_chg']:.2f}%")

# 获取股票池行情
stock_pool = ['000001.SZ', '000002.SZ', '600000.SH']
df = client.get_stock_pool_quotes(stock_pool)
print(df[['ts_code', 'name', 'price', 'pct_chg']])
```

### 示例 3：提交订单

```python
from src.trader.broker_api import RealBroker

broker = RealBroker(broker_type='huatai', config_path='config/broker_config.json')
broker.connect()

# 提交买入订单
order_id = broker.submit_order(
    ts_code='000001.SZ',
    direction='buy',
    price=10.50,
    volume=1000,
    strategy_name='manual_test'
)

if order_id:
    print(f"订单已提交：{order_id}")
else:
    print("订单提交失败")

broker.disconnect()
```

## 风险控制

### 熔断机制

系统内置三级熔断：

| 级别 | 触发条件 | 响应 |
|------|---------|------|
| HIGH | 单只股票亏损 10% | 止损该股票 |
| CRITICAL | 组合亏损 5% | 全部清仓 |
| CRITICAL | 单日亏损 3% | 全部清仓并暂停交易 |

### 实时告警

以下情况会触发钉钉告警：

- 价格大幅波动（5% 以上）
- 数据延迟超过 60 秒
- 连续网络错误（3 次以上）
- 账户亏损告警
- 熔断触发

### 交易时段限制

默认避免以下时段交易：

- 09:30 之前（集合竞价）
- 14:55 之后（尾盘）

可在 `settings.py` 中调整：
```python
REAL_TRADING_RISK_CONFIG = {
    'morning_start_time': '09:35',
    'afternoon_end_time': '14:55',
}
```

## 常见问题

### Q1: easytrader 连接失败

**原因**：
1. 券商客户端未安装
2. 配置文件路径错误
3. 账号密码错误

**解决**：
```bash
# 确认 easytrader 安装
pip show easytrader

# 检查配置文件
cat config/broker_config.json

# 测试连接
python -c "from src.trader.broker_api import RealBroker; b = RealBroker(...); print(b.connect())"
```

### Q2: 新浪行情获取失败

**原因**：
1. 网络连接问题
2. API 频率限制
3. 股票代码格式错误

**解决**：
- 检查网络连接
- 降低请求频率（增加间隔）
- 确认代码格式：`000001.SZ` 或 `600000.SH`

### Q3: 订单提交成功但成交失败

**可能原因**：
1. 价格偏离市场价太大
2. 涨跌停无法成交
3. 非交易时间

**解决**：
- 使用实时行情价格
- 检查是否在交易时段
- 查看订单状态和券商返回信息

### Q4: 钉钉通知不发送

**检查步骤**：
1. 确认 `ENABLE_DINGDING_NOTIFY=true`
2. 确认 webhook 地址正确
3. 测试 webhook 是否有效

```python
from src.utils.dingtalk_notifier import DingTalkNotifier
n = DingTalkNotifier()
n.send_text("测试消息")
```
