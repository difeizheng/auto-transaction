## 二、夏普比率优化详情

### 2.1 核心优化措施

**模块**: `src/strategy/sharpe_optimizer.py`

| 优化项 | 参数 | 作用 |
|--------|------|------|
| 波动率过滤 | max_volatility_threshold=4% | 跳过高风险股票 |
| 稳定性因子 | min_stability_threshold=0.6 | 优先交易趋势稳定股票 |
| 分级止盈 | profit_lock_trigger=8% | 盈利 8% 后部分锁定利润 |
| 增强市场过滤 | - | 更准确的牛熊识别 |

### 2.2 策略参数调整

**文件**: `src/strategy/optimal_strategy.py`


### 2.3 预期效果

- 紧止损 (3.5%) 减少单笔亏损
- 波动率过滤避开异常亏损
- 稳定性因子提高收益质量
- 分级止盈保护利润
- **综合预期：夏普比率提升 40-60%**

## 三、胜率优化详情

### 3.1 核心优化措施

**模块**: `src/strategy/win_rate_optimizer.py`

| 优化项 | 权重 | 作用 |
|--------|------|------|
| 动量因子 | 1.5 分 | 选择强势上涨股票 |
| 资金流向 | 1.5 分 | 跟踪主力资金动向 |
| 强势股筛选 | - | 只交易强度前 30% |
| 信号置信度 | 60%+ | 过滤低质量信号 |

### 3.2 新增加分因子

综合评分从 10.5 分扩展到 13.5 分:

```
原因子 (10.5 分):
- 均线金叉 2.0 分
- 完美多头排列 1.5 分
- MACD 多头 1.5 分
- RSI 健康 0.5 分
- 布林带下轨 1.0 分
- 成交量放大 1.5 分
- 趋势向上 1.5 分

新因子 (3.0 分):
- 动量因子 1.5 分 (价格动能)
- 资金流向 1.5 分 (主力动向)
```

### 3.3 入场条件优化

```python
# v4.0 新增过滤
if should_skip_trade_due_to_momentum(ts_code):
    continue  # 动量不足跳过

if should_filter_stock(ts_code):
    continue  # 强度不足过滤
```

### 3.4 预期效果

- 动量因子提高买入即涨概率
- 资金流避免散户陷阱
- 强势股筛选提高质量
- **综合预期：胜率提升 3-5% (51.4%→55%+)**
