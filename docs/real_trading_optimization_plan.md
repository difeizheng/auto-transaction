## 八、关键决策点

### 决策点 1：策略方向选择
在阶段一完成后，根据回测结果决定：
- 如果胜率提升至 50%+ → 继续优化当前策略
- 如果胜率仍低于 50% → 考虑更换策略框架（如动量策略、均值回归）

### 决策点 2：实盘资金规模
在模拟盘验证完成后，决定实盘资金：
- 保守方案：10-20 万起步
- 中性方案：50-100 万起步
- 激进方案：100 万 + 起步

### 决策点 3：策略迭代频率
- 建议：每月复盘一次，每季度优化一次
- 避免：频繁优化导致过拟合
