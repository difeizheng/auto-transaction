## 🔍 发现的核心问题

### 问题：Tushare API 限流导致系统无法稳定运行

**现象**:
- 系统启动后频繁调用 Tushare API
- 每分钟限制 50 次，但实际调用数百次
- 大量 ERROR 日志
- 系统运行 3 分钟后退出

**根本原因**:
```
实时价格刷新机制设计缺陷：
1. Sina API 在非交易时段返回空数据
2. 系统自动切换到 Tushare 备用数据源
3. 44 只股票 × 每 30 秒刷新 = 88 次/分钟 >> 50 次限制
4. 触发限流，无法获取数据
5. 系统退出
```

**影响**:
- 系统无法长时间运行
- 无法验证策略有效性
- 无法积累净值数据
