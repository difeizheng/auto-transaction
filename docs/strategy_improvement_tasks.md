## 参数敏感性测试结果 (2026-03-20)

**测试范围**:
- 止损：5%, 7%, 8%, 10%
- 止盈：15%, 20%, 25%, 30%
- 信号阈值：3.5, 4.0, 4.5
- 总计：48 个参数组合

**最优参数组合**:

### 激进型 (最高收益)
- 止损：**5%**
- 止盈：**25%**
- 信号阈值：**4.0**
- 回测表现：年化 7.02%, 夏普 0.38, 回撤 9.90%, 胜率 42.9%, 盈亏比 1.48

### 稳健型 (最高夏普)
- 止损：**10%**
- 止盈：**25%**
- 信号阈值：**4.0**
- 回测表现：年化 6.23%, 夏普 0.39, 回撤 9.09%, 胜率 50.0%, 盈亏比 1.38

**关键发现**:
1. 25% 止盈水平表现最佳，显著优于 15%/20%
2. 小止损 (5%) 带来更高收益，大止损 (10%) 带来更高胜率
3. 阈值 4.0 是最优平衡点

## 阶段一：优化止损止盈机制

**目标**: 提高盈亏比至 2.0+

**文件**: `src/strategy/optimal_strategy.py`

**改动内容**:
- [x] 第 51 行：`base_stop_loss` 从 `0.08` 改为 `0.07` (8% → 7%)
- [x] 第 52 行：`base_take_profit` 从 `0.20` 改为 `0.20` (维持 20%)
- [x] 第 55 行：新增 `trailing_stop_trigger: float = 0.12` (移动止损触发点 12%)
- [x] 第 273 行：移动止损触发从 `1.10` 改为 `(1 + self.params.trailing_stop_trigger)`

**优化过程**:
| 版本 | 止损 | 止盈 | 盈亏比 | 说明 |

| 初始 | 8% | 20% | 1.33 | 基线 |

| V2 | 7% | 20% | 2.33 | 最优组合 ✅ |

**预期效果**: 止盈更容易达成，止损更紧，盈亏比提升至 3:1
**实际效果**: 盈亏比 2.33，达成目标 ✅
